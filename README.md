# MCA AI Lab Set 9: Intelligent Travel Planner (Turbo Prolog 2.0)

## Overview
An Intelligent Travel Planner built in **Turbo Prolog 2.0** for **MCA Artificial Intelligence Lab (Set 9)**. It models six cities (`City A` to `City F`) and directed connections with **travel cost (Rs.)**, **travel time (hours)**, and **distance (km)**, finds possible routes dynamically, avoids a specified city when requested, handles unavailable routes, compares cheapest vs. fastest options, and explains why the selected route was chosen.
